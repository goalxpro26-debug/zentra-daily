A cyber-security start-up says it has used artificial intelligence to uncover a critical vulnerability in Java, one of the world's most widely used programming languages, that had gone unnoticed for more than a decade.

The flaw, named Java4Shell, sits in Java's memory functions. It could allow an attacker to remotely run unwanted commands against a system's memory — one of the most common routes hackers use to exploit or crash a system. The researchers say the bug had been hiding in plain sight for 12 years.

The discovery was made by Calif, a tech start-up that recently found a similar flaw in the web language PHP. In this case, the system probing Java was GPT-6 Cyber, an OpenAI model that has not yet been released to the public. Computer scientist Professor Toby Walsh said AI is now exposing flaws far more quickly, including ones so obscure that people alone might never have found them. He noted that managing memory safely is central to what Java is for, which is what makes this flaw so unlikely — and so serious.

Java matters because it sits underneath so much of the modern economy. First released in 1995, it is used by nearly all of the world's largest companies, along with banks, hospitals and governments, and it underpins banking, national security, aviation and telecommunications. Calif describes the language as the "beating heart of the modern economy." Cyber-security expert Dr Pedram Hayati said the flaw could compromise critical financial systems and customer data, noting that in Australia almost every bank relies on Java to manage critical transaction data.

Oracle, which owns Java, has not acknowledged the bug, but on Tuesday it released a "critical patch update" containing security vulnerability fixes. The BBC said it had contacted Oracle for comment. It is not yet clear whether any company or platform has been affected, and experts warn that hackers could now try to identify the bug themselves if it is not fixed.

The discovery comes after a run of serious technology failures. A major Microsoft outage, Apple services going down, a network failure that grounded flights across the United States, and thousands of customers at major US banks — including JP Morgan Chase, Wells Fargo and Bank of America — reporting trouble accessing their accounts. The US National Security Agency said its internal communications went offline on Tuesday for what it called scheduled routine maintenance. US Secretary of State Marco Rubio said there was "zero evidence" the incidents were related.

The Java find follows Calif's earlier discovery in PHP, which Professor Alan Woodward of the Surrey Centre for Cyber Security said left about 30 million websites vulnerable. OpenAI's president, Greg Brockman, said earlier this month that the company is moving a quarter of its staff to focus on cyber-security work.

Anthropic said on Tuesday that Claude users can now turn the interactive tools the chatbot builds — known as artifacts — into desktop apps on Mac and Windows. The "Install as app" feature is rolling out in beta on every plan, including the free tier.

An artifact installed as an app gets its own icon and opens in its own window, instead of living inside a Claude conversation. The process is short: describe the tool to Claude, try it out as an artifact, then choose "Install as app" from the artifact's Share menu. No packaging, code signing or API key is involved, and the resulting app can be shared with other Claude users. The kinds of tools Anthropic points to are small and practical — a timer, a tracker, a tool that renames photos — rather than full-scale software.

Installed apps can do more than a web page could. They can send desktop notifications, register global keyboard shortcuts, float in an always-on-top window, and add an item to the Mac menu bar or the Windows system tray. They can also call on Claude and on services a user has linked to it, so a tracker that reads a calendar no longer has to live in a browser tab.

That extra reach is where the permission system comes in. Every installed app starts at the default level, where it can only do what it could do inside a browser. A second level, app permissions, lets it request desktop features such as notifications and shortcuts. The highest level, full computer access, lets an app run programs and read, change or delete files without asking each time. Anthropic says it does not review apps before they are installed, and full access is only available for apps a person built themselves — or, on Team and Enterprise plans, apps built by someone in their own organisation. Permissions are requested again after every update, including the owner's own edits.

There are limits to what the feature offers for now. An installed app needs an internet connection and an active Claude sign-in to open at all, and anything it asks Claude counts toward the user's plan usage limits. It requires Claude for Mac or Windows version 6.28899.0 or later. Document-style artifacts — Claude Docs, Slides and Sheets — cannot be installed, and Linux, the web and mobile are not supported at launch. For Team subscribers the feature is switched on by default, with full computer access off; for Enterprise subscribers it stays off until an administrator enables it. Organisations with HIPAA-ready configurations do not get it.

The move takes artifacts out of the chatbot and onto the desktop, where the small tools people build with Claude can sit alongside the programs they already use. It is the second Claude update this week aimed at people building with the tool.
